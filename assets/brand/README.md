# SupaCraft brand

The mark: an octopus. One brain (the dome) steers many smaller nodes, the way
one `supacraft.json` drives the database, auth, functions and cron jobs.

| File | Use |
|---|---|
| `supacraft-mark.svg` / `-black.svg` | Main mark on light backgrounds (README, docs) |
| `supacraft-mark-white.svg` | Main mark on dark backgrounds |
| `supacraft-mark-small.svg` | Simplified drawing for 48 px and below (solid nodes, bigger eyes) |
| `supacraft-mark-app-icon.svg`, `icon-*.png`, `apple-touch-icon.png` | App / social avatar on a #111111 tile |
| `favicon.svg`, `favicon.ico`, `favicon-*.png` | Browser tab; `favicon.svg` switches to white in dark mode |
| `site.webmanifest`, `head-snippet.html` | Drop-in `<head>` tags for a web page |

Rules: one colour only (black or white), keep clear space of at least one
eye-width around the mark, and use the small drawing below 48 px.
